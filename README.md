# SQL Business Analysis Project

## Project Overview
This project uses SQL to analyze business sales data and generate insights related to revenue performance, product sales, and regional trends.

## Tools Used
- SQL
- DBeaver
- SQLite
- Business Analytics

## SQL Concepts Demonstrated
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions
- Filtering
- Revenue Analysis

## Key Business Questions Answered
- Which regions generate the most revenue?
- What are the top-selling products?
- Which product categories are most profitable?
- How does monthly revenue change over time?
